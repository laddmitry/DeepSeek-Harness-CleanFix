# Очищенный Harness для локальной Windows 11

Изменённая версия DeepSeek Harness для работы с локальной моделью. Активные каналы DeepSeek отключены и запрещены при загрузке плагинов. Web открывается по локальному токену. Исходники, собранный runtime, Node, PowerShell, Ollama и Qwen3:0.6b входят в этот репозиторий; установка не скачивает зависимости.

1. Скачайте ZIP **конкретного проверенного коммита** либо клонируйте репозиторий.
2. На чистой Windows 11 Pro x64 следуйте [инструкции установки](docs/clean/INSTALL_WINDOWS11_RU.md).
3. После установки войдите как DSHAudit и откройте Harness-First-Run. Для следующих запусков используйте Harness-Local.

[Что изменено](docs/clean/CHANGES_RU.md) · [Проверки и результаты](docs/clean/TEST_RESULTS_RU.md) · [Ограничения и безопасность](docs/clean/SECURITY_RU.md) · [Публикация через GitHub Desktop](docs/clean/PUBLISH_GITHUB_DESKTOP_RU.md).

Полный комплект занимает около 1 ГБ: бинарные зависимости разбиты на проверяемые части меньше 50 MiB. Git LFS и дополнительные release assets не требуются. Используйте целый репозиторий, сохраняя папку payload.
