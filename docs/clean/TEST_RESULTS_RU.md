# Проверки публикационной версии

Публикационный комплект проверен 16 октября 2026 года в отдельной Windows 11 Pro x64, заново установленной с ISO: build 26300.9457, 2 vCPU, 6 ГБ RAM, диск 80 ГБ; сетевые адаптеры отключены. Установка завершилась, хеши всех шести payload сверены в гостевой системе. Под обычным DSHAudit прошли 13 ACL-проверок и настройка английской/русской раскладок. Итог повторного запуска: **6 PASS, 0 FAIL**. ## Сценарии

Установка без загрузок, новый вход DSHAudit, English/Russian keyboard, 13 проверок ACL, SDK write/read/glob/grep с Windows worker, headless, ACP, foreground spawn/fork, Web token/cookie и восстановление истории после перезапуска, реальная Ollama write/read. Драйверы поставляются в kit/verification; общий запуск — kit/Run-Verification.ps1.

Протокольные smoke-тесты используют детерминированный локальный API. Отдельный тест RealModelTools использует настоящую Qwen3:0.6b. Ответ модели проверяется вместе с файлом и событиями инструментов; один текстовый ответ не принимается за успех.

## Что остаётся

Автономный запуск контроллера через службу или Task Scheduler в этой VM не подтверждён: временные тестовые задачи не стартовали, хотя интерактивный DSHAudit прошёл проверки. Сценарии развёртывания используют вход DSHAudit; серверный сервис требует отдельной настройки и проверки.

Новый SDK-процесс не принимает сохранённый session ID автоматически; для resume проверяется Web/headless. Background follow-up через send_message, все negative sandbox cases, продолжительные coding-задачи, качество маленькой модели, все поддерживаемые версии Windows и общий аудит native/UDP/дочерних процессов не проверены. Shell/MCP/PTC и общий web-доступ остаются выключенными. Гостевая UI-проверка через API не равна ручному прохождению всех экранов браузера.

## Причина первого сбоя модели

Первый RealModelTools завершился по внутреннему лимиту 180 секунд: Ollama загрузила модель за 14,45 секунды, обработала первый prompt из 2925 токенов и вернула HTTP 200 примерно через 130 секунд; следующий запрос был отменён при остановке теста. Генерация шла со скоростью около 2,85 токена/с. Бюджет теста увеличен до 600 секунд, внешний предел процесса — до 720 секунд; проверки файла и событий write/read сохранены. Повторный запуск прошёл все проверки, включая реальную модель. Сервер Ollama к повторному запуску уже обслуживал первый тест; время 56,606 секунды не является гарантией скорости холодного старта.
