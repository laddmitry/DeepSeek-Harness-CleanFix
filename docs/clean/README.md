Версия определяется [VERSION.json](../../deploy/VERSION.json), содержимое payload — [манифестом SHA-256](../../payload/manifest.json), исходники и документация — FILES.sha256.json в корне. Окончательная идентичность Git-версии — полный SHA коммита. Публикуйте именно подготовленный и проверенный коммит; изменение файлов создаёт новую версию, для которой прежний результат автоматически не действует.
